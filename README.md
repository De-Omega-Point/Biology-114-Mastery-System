## ⚙️ 5. CORE WORKFLOW (HOW TO USE PROPERLY)

Follow this loop for every study session:

```
LEARN → DRAW → EXPLAIN → TEST → FIX
```

### Practical Flow:

1. Go to **Chapter Navigator**
2. Understand one concept
3. Draw it (mentally or on paper)
4. Explain it out loud
5. Go to **Quiz Lab**
6. Fix mistakes immediately

## ⚠️ 8. COMMON MISTAKES

| Mistake                 | Why it happens   | Fix                     |
