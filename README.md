# 🧬 Biology 114 Mastery System

> A calm, visual, ADHD-friendly learning system designed to turn Biology 114 into a structured, high-retention experience.

---

## 🚀 TL;DR

**What this is:**
A single-page interactive web app for mastering Biology 114 using visual learning, structured flows, and active recall.

**Why it exists:**
Traditional study methods overwhelm. This system simplifies, structures, and accelerates learning.

**Who it’s for:**

* Visual learners
* ADHD / autism-friendly learning styles
* Students who want clarity, not chaos

---

## 🧠 Core Philosophy

This system is built on one idea:

```
Understanding > Memorisation
Structure > Overload
Action > Passive reading
```

Instead of cramming content, this system trains:

* Systems thinking
* Visual mapping
* Active recall
* Rapid verification

### 🧭 1. Chapter Navigator

* Breaks Biology 114 into **9 clean modules**
* Each chapter includes:

  * Core concept
  * Visual flow diagram
  * Key points
  * Verification question

## ⚠️ Common Mistakes

| Mistake           | Why it happens   | Fix               |
| ----------------- | ---------------- | ----------------- |
| Just reading      | Feels productive | Use the loop      |
| Skipping diagrams | Seems optional   | Draw everything   |
| Not testing       | Avoid discomfort | Use quiz daily    |
| Overwriting notes | Too much info    | Keep notes simple |

---

## 💡 Pro Tips

* Say answers **out loud** → boosts retention
* Draw messy diagrams → perfection slows learning
* Use flashcards before sleep → memory lock-in
* Use focus mode → reduce visual noise
